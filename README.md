# adblock

## adblock-list.txt

Cosmetic filter list (uBlock Origin / AdGuard syntax) for hiding page components.

Raw link for adding to a filter list:
https://raw.githubusercontent.com/Fankrits/adblock/main/adblock-list.txt

## manga-ad-remover.user.js

Userscript that removes ads on speed-manga.com, god-manga.com and go-manga.com.

Install: add Tampermonkey (or Violentmonkey), then open the raw file link:
https://raw.githubusercontent.com/Fankrits/adblock/main/manga-ad-remover.user.js
